Este projeto tem como objetivo verificar se determinadas roles possuem privilégios restritos.  
Ele retorna se a role analisada contém privilégios restritos ou não, além de permitir a listagem completa de todos os privilégios (restritos e não restritos).

- Verificação de privilégios restritos em uma role específica.
- Retorno booleano indicando se a role possui privilégios restritos.
- Listagem completa de todos os privilégios associados à role.
- Diferenciação clara entre privilégios restritos e não restritos.
